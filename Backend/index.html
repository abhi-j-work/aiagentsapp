The Automated Governance Workflow

Automatically connects to the database and pulls the schema for analysis.

2

3

Generate SQL

Generates data masking SQL views based on the AI classifications.

4

Review & Refine

An AI peer-review checks the generated SQL for syntax and logic errors before application.

5

Apply Views

Safely applies the reviewed views to the database, ensuring data is masked at the source.

Core Capabilities Deep Dive

AI-Powered PII Classification

The agent uses an LLM to scan schemas and intelligently tag columns, distinguishing between sensitive PII, foreign keys, and general data with high accuracy.

Automated Data Quality Checks

Instead of relying on rigid rules, the agent leverages an LLM to find semantically invalid data, such as improperly formatted phone numbers, emails, or dates.

Natural Language to SQL (NL-to-SQL)

Empower non-technical users to query data directly using plain English. The agent translates their questions into executable SQL, runs it, and returns the results instantly.
